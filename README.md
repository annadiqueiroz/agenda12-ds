# Meus Sites Favoritos 🌐

## 📚 Sobre o projeto

Este projeto foi desenvolvido como parte da **Atividade da Agenda 12**, da disciplina de **Desenvolvimento de Sistemas**, do curso **Técnico em Desenvolvimento de Sistemas da ETEC**.

A atividade consiste na criação de uma página web utilizando HTML, com o objetivo de apresentar cinco sites favoritos, suas respectivas imagens e links de acesso.

## 💻 Tecnologias utilizadas

- HTML5
- Visual Studio Code
- Navegador web para visualização da página

## 🛠️ Funcionalidades

- Exibição do título da página e identificação da autora.
- Apresentação dos nomes dos cinco sites favoritos.
- Exibição das imagens representativas de cada site.
- Links que direcionam o usuário aos respectivos sites, abrindo em uma nova aba.
- Utilização de comentários no código HTML para explicar as tags utilizadas.
